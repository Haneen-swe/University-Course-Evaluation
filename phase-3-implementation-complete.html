Privacy Architecture — Implemented

The responses table has no student_id column in schema.prisma.
The anonymous submission in evaluations.router.ts uses prisma.$transaction([…]) to atomically write responses (no student ID) and the participation token (no response ID) — in two separate tables with no join key.

Architecture Enforced

Design DecisionImplementation
Anonymity at schema levelschema.prisma — Response model has no studentId field
RBAC middlewareauthorize('admin','dept_head') factory on every protected route
JWT + refresh tokensAccess (15 min) in Bearer header; refresh (7d) in httpOnly cookie; deny-list in Redis
Append-only audit logAll admin actions call auditRepository.insert(); no update/delete methods on audit repo
Minimum threshold enforcementofferings.router.ts /release checks count < threshold before allowing release
4-layer module patternRouter → Controller → Service → Repository in every domain module
IP anonymisation in logsrequestLogger.ts zeroes last octet; auditRepository also zeroes last octet
Rate limitingRedis-backed; auth: 10/15 min; password reset: 5/hour; submission: 3/5 min
